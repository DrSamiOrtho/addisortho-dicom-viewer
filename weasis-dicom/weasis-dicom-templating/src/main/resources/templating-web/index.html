Open an X-ray to template

Open this page from an X-ray in the imaging viewer, or drop a DICOM, PNG or JPEG file or a saved project (.aotp) here. A picture or file you open stays in this browser.

    DICOM is best (full grey range and the machine's scale; compressed DICOM from CDs is fine). PNG and JPEG work too, calibrated on the ball.

    Trial software for planning practice; not for clinical decisions until validated and approved. Implants: Addis Ortho range, outlines from the manufacturer's 1:1 template sheets and 3D models.
